# Working print — 1.7.0

Applied interface-disruptor, interaction-inventor, ui-ux-pro-max and dieter-rams-principles from the approved design proposal. The product objects remain photograph, film, region, mask, reference and version. The primary verbs are choose, judge, adjust, compare and keep.

The default interface now uses five task tools and one contextual inspector. Native controls, focus, numeric entry and reset menus accompany direct manipulation. Film previews and Explore candidates render the actual photograph. The loupe crops a full-resolution developed image in original coordinates; its displayed size is divided by display scale for one image pixel per display pixel. Mask coordinate sliders remain available in addition to painting/placement. Scanner and processing details are progressively disclosed rather than removed.

Whole-image tone selection uses the original pixel’s luminance to select shadows, midtones/exposure or highlights. Explicit Target overrides automatic choice. New bidirectional shadow/highlight curve parameters default neutral for old sessions. Glow sampling suggests a threshold from a bright original pixel; it is a starting point, not object recognition. Small previews approximate texture at fit scale; the loupe is the reference for grain inspection.

Explore snapshots the recipe before showing three variants. Its step slider adjusts candidate distance; no session edit occurs until choosing a candidate. Variations affect one defined parameter per tool. Bypass is preview-only, with exports and version capture disabled until returning to edit. Scoped reset preserves other tools and, for Local, mask geometry. One completed direct gesture produces one undo step.

Kept versions persist per Photograph/PhotoRecord as recipe snapshots with stable UUIDs. Legacy session records decode missing versions as empty. Comparisons render the snapshot at the same resolution and coordinates as the current image. Zoomed side-by-side comparison uses two native NSScrollViews whose clip origins are synchronized in both directions; zoom changes preserve the normalized viewport center. Original-only B comparison always clears a version reference to retain its expected meaning. Favorite film IDs are persisted separately from photo recipes.

Validation: 41 tests pass, including prior processing/export behavior, scoped reset and bypass, bounded Explore candidates, kept-version persistence/restore/delete/undo, legacy records, favorite navigation, bidirectional tone curves and two-way synchronized comparison scrolling. Native checks cover numeric entry, Keep version, Explore selection, bypass export disabling, 100% loupe movement, direct tonal dragging/undo, bright-point glow, saved-version comparison and Paint/Erase controls. The focused tool inspector and full image were visually reviewed on the current Mac. No formal accessibility compliance or user-study outcome is claimed.
